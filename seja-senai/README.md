# SEJA SENAI

O SEJA SENAI é um projeto que visa a criação de um sistema de acesso a informação, inscrição e a dados de forma totalmente online. O objetivo é tornar o processo mais acessível, prático e eficiente. 

A solução atua de forma híbrida e será implementada através de um site web para gerenciar as inscrições e um aplicativo que funcionará como carteirinha digital. O sistema foi idealizado para evitar a superlotação nas unidades presenciais e facilitar o acesso de pessoas com dificuldades de locomoção.

## Estrutura do Repositório

* **/backend:** API e regras de negócio (Java + Spring Boot).
* **/frontend-web:** Interface web para os candidatos (HTML + CSS).
* **/mobile-app:** Aplicativo da carteirinha digital (Kotlin).
* **/database:** Scripts SQL para o banco de dados (MySQL).
