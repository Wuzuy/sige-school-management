# Mobile App

Aplicativo mobile desenvolvido em **Kotlin** para visualização e gerenciamento da carteirinha digital do aluno.

## Tecnologias
- Kotlin
- Android SDK
- Jetpack Compose (ou XML)
- Retrofit (para consumir API)

## Estrutura
```
mobile-app/
├── app/
│   ├── src/
│   │   ├── main/
│   │   └── test/
│   └── build.gradle
├── gradle/

```
