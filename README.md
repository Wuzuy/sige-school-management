# seja-senai

Sistema de gestão para instituições SENAI

## Estrutura do Projeto

```
seja-senai/
├── backend/             # Java + Spring Boot (API e Regras de Negócio)
├── frontend-web/        # HTML, CSS e JS (Inscrição e Admin)
├── mobile-app/          # Kotlin (Aplicativo da Carteirinha)
├── docs/                # Prototipagem Figma, Diagramas e Pesquisas
├── database/            # Scripts SQL do MySQL
└── README.md            # Documentação principal do projeto
```

## Módulos

### Backend
Desenvolvido em **Java com Spring Boot**, contém:
- API REST
- Regras de negócio
- Integração com banco de dados

### Frontend Web
Desenvolvido em **HTML, CSS e JavaScript**, contém:
- Sistema de inscrição
- Painel administrativo

### Mobile App
Desenvolvido em **Kotlin**, contém:
- Aplicativo da carteirinha digital do aluno
- Acesso rápido às informações

### Docs
Contém toda a documentação do projeto:
- Protótipos Figma
- Diagramas de arquitetura
- Pesquisas de usuário
- Documentação técnica

### Database
Scripts SQL para **MySQL**:
- Scripts de criação de tabelas
- Scripts de migração
- Scripts de dados iniciais (seeds)
