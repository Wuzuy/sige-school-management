Visão geral

O projeto SEJA SENAI é composto por frontend estático (HTML/CSS/JS) e backend Java Spring Boot com autenticação JWT e APIs REST.

Frontend

Páginas estáticas e lógica central em scripts.js.

Backend

APIs para usuários, cursos, unidades, inscrições e editais.

Administração

Portal da secretaria com padrão CRUD: criar, pesquisar, filtrar, editar e deletar.
