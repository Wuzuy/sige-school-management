🎯 Visão Geral do Sistema

O SEJA SENAI é um sistema completo que automatiza o processo seletivo de cursos profissionalizantes, desde a inscrição até a matrícula online, com portais dedicados para alunos e secretaria.

👨‍🎓 Portal do Aluno

Interface intuitiva para visualização de cursos, inscrição online, acompanhamento de status com timeline visual e matrícula digital com aceite de contrato.

✓ Inscrição Online ✓ Timeline Visual ✓ Matrícula Digital

🏢 Portal Administrativo

Sistema CRUD completo para gestão de cursos, unidades, usuários e editais. Dashboard com estatísticas e controle de etapas do processo seletivo.

✓ CRUD Completo ✓ Dashboard ✓ Relatórios

🔐 Segurança Avançada

Múltiplas camadas de proteção: autenticação JWT robusta, rate limiting, senhas fortes, proteção contra brute force e HTTP security headers.

✓ JWT ✓ Rate Limiting ✓ Brute Force Protection

📱 100% Responsivo

Interface adaptada para desktop, tablet e mobile. Menu hamburger, gestos touch e otimizado para todos os tamanhos de tela.

✓ Desktop ✓ Tablet ✓ Mobile

🚀 Início Rápido (3 Minutos)

✨ Método Mais Fácil: Use o Script Automático!

Criamos scripts que fazem TUDO automaticamente - backend, frontend e dados de teste:

.\iniciar-tudo.bat

✅ Este comando inicia backend + frontend + popula dados | ⏱️ Pronto em 1-2 minutos

📖 Ver Guia Completo de Scripts

📋 Pré-requisitos

  • Java 21+ - Necessário para o backend Spring Boot
  • Maven - Incluído via wrapper (mvnw.cmd)
  • MySQL 8.0+ (produção) ou H2 (testes - sem instalação)
  • Python 3.x ou Node.js - Para servidor HTTP do frontend
  • Navegador moderno - Chrome, Firefox, Edge, Safari

⚡ Passo a Passo Manual (Se preferir controle total)

1. Configurar Banco de Dados

Edite backend/src/main/resources/application.properties:

# Para testes (recomendado) - Banco em memória, sem instalação
spring.profiles.active=h2

# OU para produção
spring.profiles.active=mysql

2. Iniciar Backend

cd backend
mvnw.cmd spring-boot:run

Aguarde a mensagem: Started SejaSenaiApplication in X seconds

3. Iniciar Frontend

# Com Python
cd frontend-web/static
python -m http.server 5500

# OU com Node.js
npx http-server frontend-web/static -p 5500

4. Popular com Dados de Teste (Opcional)

powershell -ExecutionPolicy Bypass -File popular-dados-teste.ps1

Cria automaticamente: 1 admin, 3 usuários, 4 unidades, 5 cursos e 3 editais

5. Acessar Sistema

  • Frontend: http://localhost:5500
  • Backend API: http://localhost:8080/api
  • H2 Console: http://localhost:8080/h2-console (se H2 ativo)
