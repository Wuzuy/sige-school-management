Manual do Candidato

Guia passo a passo para utilizar o Portal de Inscrição do SIGE — desde o cadastro até a matrícula.

1. Acessando o Sistema

Acesse o Portal de Inscrição através do seu navegador. Na página inicial, você encontrará a tela de login com as opções de criar uma nova conta ou entrar com um login existente.

  1. Cadastro: Clique em "Criar conta" e preencha seus dados pessoais (nome completo, CPF, e-mail, senha).
  2. Login: Após criar a conta, informe seu e-mail e senha para acessar o sistema.
Nota: A opção "Entrar como Visitante" foi removida. Apenas usuários cadastrados podem acessar o sistema. Candidatos são direcionados automaticamente para a página de cursos.
Login / Cadastro Tela inicial com formulário de autenticação e editais publicados.

2. Visualizando Cursos

Após autenticado, você será direcionado à página de cursos. Nela é possível visualizar todos os cursos disponíveis para inscrição.

  • Utilize os filtros por unidade, turno e status para refinar a busca.
  • Clique em um curso para ver os detalhes: descrição, carga horária, vagas disponíveis e requisitos.
  • Para se inscrever, clique no botão "Inscrever-se" no card do curso desejado.
Cursos Disponíveis Lista de cursos com filtros e botão de inscrição.

3. Realizando Inscrição

Ao clicar em "Inscrever-se", você será levado ao formulário de inscrição. Preencha todos os campos obrigatórios com atenção.

  1. Dados Pessoais: Confirme seu nome, CPF, data de nascimento e contato.
  2. Escolaridade: Informe seu nível de escolaridade, instituição de ensino e ano de conclusão.
  3. Preferência de Turno: Selecione o turno desejado (matutino, vespertino ou noturno).
  4. LGPD - Consentimento: Leia e aceite a Política de Privacidade marcando a caixa de consentimento obrigatória.
  5. Confirmação: Revise os dados informados e clique em "Confirmar Inscrição".
LGPD: Conforme a Lei Geral de Proteção de Dados (LGPD), é obrigatório consentir com a Política de Privacidade antes de finalizar sua inscrição. Seus dados serão utilizados exclusivamente para fins acadêmicos e administrativos.
Formulário de Inscrição Preenchimento dos dados pessoais e escolaridade para inscrição no curso, com checkbox de consentimento LGPD.

4. Acompanhando Status

Após realizar a inscrição, você pode acompanhar o andamento do processo seletivo na página de status.

  • Acesse a opção "Meu Status" no menu principal.
  • A linha do tempo exibe cada etapa do processo: inscrição recebida, documentos em análise, aprovado/reprovado.
  • Você receberá notificações visuais sempre que houver atualização no status.
Acompanhamento de Status Linha do tempo com todas as etapas do processo seletivo.

5. Aceitando Matrícula

Se sua inscrição for aprovada, você poderá efetuar a matrícula diretamente pelo sistema.

  1. Acesse a página de status e localize a inscrição com status "Aprovado".
  2. Clique no botão "Efetuar Matrícula".
  3. Leia atentamente o contrato e os termos de matrícula.
  4. Marque a caixa de aceite dos termos e clique em "Confirmar Matrícula".
  5. Após a confirmação, você receberá um comprovante de matrícula para impressão.
Aceite de Matrícula Contrato e termos para confirmação da matrícula.

6. Política de Privacidade (LGPD)

O SIGE disponibiliza uma página dedicada à Política de Privacidade, acessível pelo link no rodapé ou diretamente em /privacidade.html.

  • Explica quais dados pessoais são coletados (nome, CPF, e-mail, histórico escolar).
  • Informa a finalidade do tratamento: inscrição, matrícula e gestão acadêmica.
  • Detalha os direitos do titular (acesso, correção, exclusão, portabilidade).
  • Fornece contato do Encarregado (DPO) para exercer seus direitos.
Política de Privacidade Página com informações sobre tratamento de dados conforme a LGPD.

7. Recuperando Senha

Caso você esqueça sua senha, o sistema oferece um processo simples de recuperação.

  1. Na tela de login, clique em "Esqueceu sua senha?".
  2. Informe o e-mail cadastrado na sua conta.
  3. Você receberá um e-mail com um link para redefinição de senha.
  4. Clique no link recebido e defina uma nova senha.
  5. Após redefinir, utilize a nova senha para acessar o sistema normalmente.
