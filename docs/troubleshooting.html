🚨 Problemas Comuns do Backend

❌ Erro: "Port 8080 already in use"

Sintoma

Error: listen EADDRINUSE: address already in use :::8080

Causas Possíveis

  • Backend já está rodando em outra janela
  • Outra aplicação usando porta 8080
  • Processo ficou travado após encerramento incorreto

Soluções

Solução 1: Usar script para parar 
.\parar-sistema.bat
Solução 2: Matar processo Node.js manualmente 
taskkill /F /IM node.exe
Solução 3: Identificar e matar processo específico 
# Ver qual processo usa a porta 8080
netstat -ano | findstr :8080

# Saída exemplo: TCP 0.0.0.0:8080 0.0.0.0:0 LISTENING 12345
# O número final (12345) é o PID

# Matar o processo específico
taskkill /F /PID 12345
Solução 4: Mudar a porta do backend

Edite backend/.env:

PORT=8081

⚠️ Atenção: Se mudar a porta, atualize também a URL no frontend

❌ Erro de Dependências (node_modules)

Sintoma

Error: Cannot find module 'express'
Require stack:
- C:\Users\...\sige\backend\server.js

Soluções

Solução 1: Instalar dependências 
cd backend
npm install
Solução 2: Reinstalar do zero 
cd backend
rm -rf node_modules package-lock.json
npm install
Solução 3: Verificar versão do Node.js 
node --version
# Deve ser Node.js 22 ou superior

❌ Erro de Conexão Supabase

Sintoma

Error: connect ECONNREFUSED
{
  code: 'ECONNREFUSED',
  errno: -4078,
  syscall: 'connect'
}

Causas Possíveis

  • Credenciais incorretas em backend/.env
  • Projeto Supabase pausado/inativo
  • Chave (SUPABASE_KEY) expirou ou foi revogada
  • URL do projeto errada

Soluções

Verificar credenciais

Edite backend/.env e confirme:

SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_KEY=SUA_CHAVE_ANON
Verificar projeto no Supabase Dashboard 
Acesse: https://supabase.com/dashboard/project/seu-projeto
Verifique se o projeto está ativo (não pausado)
Gerar nova chave

No Supabase Dashboard: Settings → API → Project API keys → anon public

🌐 Problemas Comuns do Frontend

❌ Erro: "Port 5500 already in use"

Sintoma

OSError: [WinError 10048] Apenas uma utilização de cada endereço de soquete 
(protocolo/endereço de rede/porta) é normalmente permitida

Soluções

Solução 1: Parar servidor
  • Pressione Ctrl+C na janela do servidor
  • Ou execute: .\parar-sistema.bat
Solução 2: Matar processo na porta 5500 
# Ver processo usando porta 5500
netstat -ano | findstr :5500

# Matar o processo
taskkill /F /PID [número_do_processo]
Solução 3: Usar porta diferente 
# Python
python -m http.server 8000

# Node.js
npx http-server -p 8000

❌ Erro: "Python não encontrado"

Sintoma

Python não foi encontrado; executar sem argumentos para instalar do 
Microsoft Store...

Soluções

Solução 1: Script tenta Node.js automaticamente

O script iniciar-frontend.bat detecta Node.js automaticamente se Python não estiver disponível.

Solução 2: Instalar Python
  1. Baixe em: python.org/downloads
  2. Durante instalação, marque: "Add Python to PATH"
  3. Reinicie o terminal
  4. Verifique: python --version
Solução 3: Usar Node.js
  1. Baixe em: nodejs.org
  2. Instale e reinicie terminal
  3. Verifique: node --version
Solução 4: Abrir HTML diretamente

Navegue até frontend-web/index.html e abra no navegador.

⚠️ Limitações: Pode ter problemas com CORS em algumas funcionalidades.

❌ Erro CORS no Console do Navegador

Sintoma

Access to fetch at 'http://localhost:8080/api/...' from origin 'file://' 
has been blocked by CORS policy

Causa

Frontend aberto diretamente (file://) em vez de via servidor HTTP

Solução

Use um servidor HTTP:

.\iniciar-frontend.bat

# OU manualmente
cd frontend-web
python -m http.server 5500

🔐 Problemas de Autenticação

❌ Token JWT Inválido

Sintoma

  • Usuário é deslogado automaticamente
  • Erro 401 Unauthorized nas requisições
  • Console mostra: "Token inválido ou expirado"

Causas Possíveis

  • Token expirou (válido por 24h)
  • Backend foi reiniciado (secret do JWT mudou)
  • LocalStorage corrompido

Soluções

Solução 1: Fazer login novamente

Simplesmente faça login novamente. O sistema gerará novo token.

Solução 2: Limpar LocalStorage 
// No console do navegador (F12)
localStorage.clear();
location.reload();
Solução 3: Usar modo anônimo

Teste em janela anônima para garantir que não há cache/dados antigos.

❌ Senha Não Atende Requisitos

Requisitos de Senha

  • Mínimo 8 caracteres
  • Pelo menos 1 letra maiúscula
  • Pelo menos 1 número
  • Pelo menos 1 caractere especial (@$!%*?&)

Exemplos Válidos

  • Admin@123
  • Senha@123
  • Teste$2024

🔑 Configurar Recuperação de Senha por Email

Funcionalidade

Sistema permite que usuários recuperem senha via link enviado por email (Gmail SMTP).

📧 Passo 1: Configurar Gmail para Aplicativos

  1. Acesse: myaccount.google.com
  2. Vá em Segurança
  3. Ative Verificação em 2 etapas (obrigatório)
  4. Após ativar, volte em Segurança
  5. Procure por "Senhas de app"
  6. Crie uma senha de app com nome "SIGE"
  7. Copie a senha gerada (16 caracteres)

⚙️ Passo 2: Configurar backend/.env

Edite: backend/.env

# Email remetente (Gmail)
EMAIL_USER=seu-email@gmail.com

# Senha de app gerada (não é a senha da conta!)
EMAIL_PASS=abcd efgh ijkl mnop

# SMTP
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587

🔄 Passo 3: Reiniciar Backend

.\parar-sistema.bat
.\iniciar-backend.bat

✅ Passo 4: Testar Recuperação

  1. Acesse: forgot-password.html
  2. Digite um email cadastrado (ex: admin@senai.com)
  3. Verifique a caixa de entrada do email
  4. Clique no link de recuperação
  5. Defina nova senha

⚠️ Problemas Comuns

  • Erro 535: Senha de app incorreta ou 2FA não ativada
  • Email não chega: Verifique spam/lixo eletrônico
  • Timeout: Verifique conexão com internet e firewall
  • Token expirado: Link vale 30 minutos, solicite novo

🔒 Segurança

  • Tokens de recuperação expiram em 30 minutos
  • Cada token pode ser usado apenas uma vez
  • Email sempre mostra mensagem genérica (não revela se email existe)
  • Senhas devem atender requisitos: 8+ caracteres, maiúscula, minúscula, número, especial

📝 Problemas com Scripts

❌ Erro 400/403 ao Executar inserir-dados.bat

Sintomas

  • Erro 400: "Solicitação Incorreta" ao criar usuários
  • Erro 403: "Proibido" ao criar unidades/cursos/editais
  • Login do admin falhando

✅ Correção Aplicada (Março 2026)

Problema de "paradoxo do admin" foi resolvido:

  • Novo endpoint: POST /api/usuarios/setup-admin
  • Permite criar primeiro admin SEM autenticação
  • Só funciona se nenhum admin existir (bootstrap inicial)
  • Admin já é criado com ROLE_ADMIN
  • Script atualizado para usar endpoint correto

Solução

Se ainda estiver com problemas:

  1. Pare o backend: .\parar-sistema.bat
  2. Limpe as tabelas no SQL Editor do Supabase
  3. Inicie novamente: .\iniciar-tudo.bat

💡 Como funciona agora

1º Admin: Use /api/usuarios/setup-admin (público)

Próximos admins: Use /api/usuarios/admin (requer ROLE_ADMIN)

❌ Erro 404 ao Executar inserir-dados.bat

Sintoma

Invoke-RestMethod : {"timestamp":"2026-03-08T...","status":404,
"error":"Not Found"...

Causas Possíveis

  • Backend não está rodando
  • Backend ainda não terminou de inicializar
  • Porta 8080 não está acessível

Soluções

Solução 1: Verificar backend 
.\verificar-status.bat
Solução 2: Aguardar inicialização

Backend demora 30-60 segundos. Aguarde mensagem:

Started SejaSenaiApplication in X.XXX seconds
Solução 3: Reiniciar backend 
.\parar-sistema.bat
.\iniciar-backend.bat
# Aguarde inicializar
.\inserir-dados.bat

❌ Erro de Permissão no PowerShell

Sintoma

... não pode ser carregado porque a execução de scripts foi desabilitada 
neste sistema

Soluções

Solução 1: Executar com bypass (não requer admin) 
powershell -ExecutionPolicy Bypass -File popular-dados-teste.ps1
Solução 2: Alterar política (requer admin) 
# Abra PowerShell como Administrador
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Solução 3: Usar .bat em vez de .ps1 
.\inserir-dados.bat

🗄️ Problemas com Banco de Dados (Supabase)

❌ Supabase Não Conecta

Verificações

1. Credenciais estão corretas?

Verifique backend/.env:

SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_KEY=SUA_CHAVE_ANON
2. Backend está rodando? 
.\verificar-status.bat
3. Projeto está ativo?

Acesse: Supabase Dashboard

Verifique se o projeto não está pausado (projetos gratuitos pausam após 1 semana de inatividade).

🗑️ Como Zerar o Banco de Dados

💡 Limpar via SQL Editor

Use o SQL Editor do Supabase para truncar todas as tabelas:

Passos:
  1. Acesse o Supabase Dashboard
  2. Vá em SQL Editor
  3. Execute o script abaixo
TRUNCATE TABLE inscricoes CASCADE;
TRUNCATE TABLE editais CASCADE;
TRUNCATE TABLE cursos CASCADE;
TRUNCATE TABLE unidades CASCADE;
TRUNCATE TABLE usuarios CASCADE;

Ou use o script .\limpar-banco.bat para automatizar.

🚨 Backup Antes de Zerar (Produção)

Sempre faça backup antes de limpar dados em produção. No Supabase:

  1. Vá em Database → Backups
  2. Clique em Create a backup

🔍 Comandos Úteis para Diagnóstico

Verificar Portas em Uso

# Backend (8080)
netstat -ano | findstr :8080

# Frontend (5500)
netstat -ano | findstr :5500

Verificar Processos Node.js

tasklist | findstr "node.exe"

Testar API com curl

# Listar editais (público)
curl http://localhost:8080/api/editais

# Login
curl -X POST http://localhost:8080/api/usuarios/login ^
  -H "Content-Type: application/json" ^
  -d "{\"email\":\"admin@senai.com\",\"senha\":\"admin123\"}"

Ver Logs do Backend

Os logs aparecem na janela que foi aberta ao executar iniciar-backend.bat
