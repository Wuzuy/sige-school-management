✨ Método Recomendado: Script Automático

🎯 O Jeito Mais Fácil (1 comando)

Use o script que faz TUDO automaticamente:

.\iniciar-tudo.bat

Este script:

  • ✅ Inicia o backend Spring Boot
  • ✅ Aguarda inicialização completa
  • ✅ Inicia o frontend (Python ou Node.js)
  • ✅ Popula banco com dados de teste

Resultado: Sistema 100% pronto para uso em 1-2 minutos! 🎉

📖 Ver Todos os Scripts Disponíveis

📋 Pré-requisitos

✅ Obrigatórios

  • Java 21+
  • Maven (incluído via wrapper)

🔄 Banco de Dados

  • H2 (testes - sem instalação) ⭐
  • MySQL 8.0+ (produção)

🌐 Servidor HTTP

  • Python 3.x OU
  • Node.js

🎬 Primeiro Uso (Passo a Passo)

Passo 1: Configurar Banco de Dados

Edite o arquivo backend/src/main/resources/application.properties:

💡 Recomendação para Testes

Use H2 (banco em memória) - não requer instalação de MySQL:

spring.profiles.active=h2

🏢 Para Produção

Use MySQL com dados persistentes:

spring.profiles.active=mysql

Nota: Certifique-se de que o MySQL está instalado e rodando.

Passo 2: Executar Script Automático

Na raiz do projeto, execute:

.\iniciar-tudo.bat

O que acontece:

  1. Nova janela abre com o backend Spring Boot
  2. Script aguarda 45 segundos para o backend inicializar
  3. Nova janela abre com o frontend (servidor HTTP)
  4. Banco é populado automaticamente com dados de teste

Passo 3: Acessar o Sistema

🌐 Frontend

http://localhost:5500

Interface do usuário

⚙️ Backend API

http://localhost:8080/api

REST API

🗄️ H2 Console

http://localhost:8080/h2-console

Apenas com H2 ativo

🔑 Credenciais de Teste

Após popular os dados, use estas credenciais:

  • Administrador: admin@senai.com / Admin@123
  • Usuário Comum: joao@teste.com / Senha@123

Passo 4: Explorar o Sistema

👨‍🎓 Como Aluno

  1. Faça login com joao@teste.com
  2. Veja cursos disponíveis
  3. Realize uma inscrição
  4. Acompanhe status na timeline
  5. Complete a matrícula (se aprovado)

🏢 Como Administrador

  1. Faça login com admin@senai.com
  2. Acesse portal administrativo
  3. Gerencie cursos e unidades
  4. Controle candidatos
  5. Visualize estatísticas

🛑 Parar o Sistema

Quando terminar, execute:

.\parar-sistema.bat

Este comando para o backend e frontend automaticamente.

🔍 Verificar Status

Para verificar se backend e frontend estão rodando:

.\verificar-status.bat

Mostra status das portas 8080 e 5500 + teste de API.

⚙️ Configuração Manual (Alternativa)

Se Preferir Controle Total

Use scripts individuais para iniciar componentes separadamente:

1. Iniciar Apenas Backend

.\iniciar-backend.bat

Aguarde mensagem: Started SejaSenaiApplication in X seconds

2. Iniciar Apenas Frontend

.\iniciar-frontend.bat

Detecta Python ou Node.js automaticamente.

3. Popular Banco (Opcional)

.\inserir-dados.bat

⚠️ Backend deve estar rodando!

🎓 Console H2 (Modo Teste)

Acessar Banco de Dados H2

Quando usando perfil H2, acesse:

  • URL: http://localhost:8080/h2-console
  • JDBC URL: jdbc:h2:mem:testdb
  • Username: sa
  • Password: (deixe em branco)

Consultas úteis:

-- Ver todos os usuários
SELECT * FROM USUARIO;

-- Ver todas as inscrições
SELECT * FROM INSCRICAO;

-- Ver cursos
SELECT * FROM CURSO;
