✨ Método Recomendado: Script Automático

🎯 O Jeito Mais Fácil (1 comando)

Use o script que faz TUDO automaticamente:

.\iniciar-tudo.bat

Este script:

  • ✅ Inicia o backend Node.js/Express
  • ✅ Aguarda inicialização completa
  • ✅ Inicia o frontend (Python ou Node.js)
  • ✅ Popula banco com dados de teste

Resultado: Sistema 100% pronto para uso em 1-2 minutos! 🎉

📋 Pré-requisitos

✅ Obrigatórios

  • Node.js 22+
  • npm (incluído com Node.js)

🔄 Banco de Dados

  • Supabase (PostgreSQL gerenciado)

🌐 Servidor HTTP

  • Python 3.x OU
  • Node.js

🎬 Primeiro Uso (Passo a Passo)

Passo 1: Configurar Ambiente

O banco de dados usa Supabase (PostgreSQL gerenciado na nuvem).

Crie o arquivo backend/.env com as credenciais:

SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_KEY=SUA_CHAVE_ANON
JWT_SECRET=secreta_sige_123
PORT=8080

Passo 2: Executar Script Automático

Na raiz do projeto, execute:

.\iniciar-tudo.bat

O que acontece:

  1. Nova janela abre com o backend Node.js/Express
  2. Script aguarda o backend inicializar
  3. Nova janela abre com o frontend (servidor HTTP)
  4. Banco é populado automaticamente com dados de teste

🛑 Parar o Sistema

Quando terminar, execute:

.\parar-sistema.bat

Este comando para o backend e frontend automaticamente.

🔍 Verificar Status

Para verificar se backend e frontend estão rodando:

.\verificar-status.bat

Mostra status das portas 8080 e 5500 + teste de API.

⚙️ Configuração Manual (Alternativa)

Se Preferir Controle Total

Use scripts individuais para iniciar componentes separadamente:

1. Iniciar Apenas Backend

cd backend
npm install
npm run dev

Servidor rodando em http://localhost:8080

2. Iniciar Apenas Frontend

.\iniciar-frontend.bat

Detecta Python ou Node.js automaticamente.

3. Popular Banco (Opcional)

Execute o script SQL database/supabase-aluno-tables.sql no SQL Editor do Supabase.

Ou use um cliente SQL como DBeaver para conectar ao banco.

🎓 Acessar Banco de Dados (Supabase)

Acessar Supabase Studio

O banco PostgreSQL fica hospedado no Supabase. Acesse:

  • URL: Supabase Dashboard
  • Table Editor: Visualize e edite dados diretamente
  • SQL Editor: Execute consultas SQL

Consultas úteis (SQL Editor):

-- Ver todos os usuários
SELECT * FROM usuarios;

-- Ver todas as inscrições
SELECT * FROM inscricoes;

-- Ver cursos
SELECT * FROM cursos;
