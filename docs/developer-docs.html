🎯 Visão Geral do Sistema

O Sistema SIGE é uma plataforma completa para gerenciamento de inscrições em cursos profissionalizantes. Permite que candidatos se inscrevam, acompanhem o status através de múltiplas etapas (análise, prova, lista de espera, matrícula) e finalizem o processo de matrícula online.

Funcionalidades Principais

👨‍🎓 Para Alunos
  • Visualização de cursos disponíveis
  • Inscrição online com formulário completo
  • Timeline visual de acompanhamento
  • Matrícula online com aceite de contrato
  • Gestão de perfil pessoal
🏢 Para Secretaria
  • Gerenciamento de cursos e unidades
  • Administração de usuários
  • Controle de etapas do processo seletivo
  • Dashboard com estatísticas
  • Relatórios consolidados

🔌 Principais Endpoints da API

Autenticação

  • POST /api/auth/login - Login e obtenção de token JWT
  • POST /api/auth/register - Registro de novo usuário

Usuários

  • GET /api/usuarios/me - Dados do usuário logado
  • PUT /api/usuarios/me - Atualizar próprio perfil
  • GET /api/usuarios - Listar todos (admin only)

Inscrições

  • POST /api/inscricoes - Criar nova inscrição
  • GET /api/inscricoes/{id} - Buscar inscrição por ID
  • PUT /api/inscricoes/{id}/etapas - Atualizar etapas do processo
  • PUT /api/inscricoes/{id}/matricula - Aceitar/recusar matrícula

Cursos, Unidades, Editais

  • GET /api/cursos - Listar todos os cursos
  • GET /api/unidades - Listar todas as unidades
  • GET /api/editais - Listar editais ativos
📝 Nota: Todos os endpoints protegidos exigem o header Authorization: Bearer <token>

🔄 Fluxo do Processo de Inscrição

  1. Cadastro: Usuário cria conta com dados básicos
  2. Seleção: Escolhe curso disponível (sistema verifica duplicatas)
  3. Inscrição: Preenche formulário completo com documentação
  4. Análise: Secretaria avalia e define se há prova
  5. Prova (se aplicável): Aluno realiza e aguarda resultado
  6. Lista de Espera: Se reprovado na prova, pode entrar na lista
  7. Matrícula: Aluno aceita contrato online
  8. Conclusão: Secretaria valida documentos finais
✅ Timeline Visual: O sistema exibe todas as etapas em tempo real com indicadores de status (concluída, em andamento, pendente)

🔒 Segurança e Autenticação

JWT (JSON Web Tokens)

  • Validade: 24 horas (86400000 ms)
  • Algoritmo: HS512 (HMAC-SHA512)
  • Armazenamento: LocalStorage no frontend
  • Proteção: JwtFilter intercepta todas as requisições

Hash de Senhas

  • Algoritmo: BCrypt com salt automático
  • Força: 10 rounds (padrão Spring Security)
  • Validação: BCryptPasswordEncoder.matches()

Controle de Acesso

Rota Permissão
/api/auth/** Público
/api/cursos, /api/inscricoes Autenticado
/api/unidades/**, /api/editais/** ROLE_ADMIN

🚀 Guia de Deploy

Opção 1: Deploy Manual

Backend: 
cd backend
./mvnw clean package -DskipTests
java -jar target/sige-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod
Frontend: 
cd frontend-web/static
npx http-server . -p 3000

Opção 2: Docker

docker-compose up -d

Opção 3: Cloud Providers

  • AWS: Elastic Beanstalk + RDS + S3 + CloudFront
  • Azure: App Service + Azure Database + Static Web Apps
  • Google Cloud: App Engine + Cloud SQL + Firebase Hosting

📊 Diagramas e Modelagem

Diagrama Entidade-Relacionamento (DER)

Entidades Principais:
  • USUARIO (id, nomeCompleto, email, senha, cpf, role)
  • UNIDADE (id, nome_unidade, endereco, telefone)
  • CURSO (id, id_unidade, nome_curso, tipo, turno, data_inicio, status)
  • INSCRICAO (id, id_usuario, id_curso, dados pessoais, etapas do processo)
  • EDITAL (id, titulo, url, ativo)
Relacionamentos:
  • USUARIO 1:N INSCRICAO (um usuário pode ter múltiplas inscrições)
  • CURSO 1:N INSCRICAO (um curso pode ter múltiplas inscrições)
  • UNIDADE 1:N CURSO (uma unidade oferece múltiplos cursos)

⚙️ Configuração do Ambiente

Pré-requisitos

  • Java JDK 21+ - Download
  • PostgreSQL 14+ ou MySQL 8+
  • Maven 3.8+ (ou usar mvnw incluído)
  • IDE: IntelliJ IDEA ou VS Code com extensões Java

Configuração application.properties

spring.datasource.url=jdbc:postgresql://localhost:5432/sige
spring.datasource.username=seu_usuario
spring.datasource.password=sua_senha
spring.jpa.hibernate.ddl-auto=update

jwt.secret=sua_chave_secreta_muito_longa_e_segura
jwt.expiration=86400000

server.port=8080

Executar o Sistema

cd backend
./mvnw spring-boot:run

# Em outro terminal
cd frontend-web/static
npx http-server . -p 3000
