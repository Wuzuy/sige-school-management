✨ Scripts de Automação Criados!

Criamos 6 scripts .bat para facilitar sua vida. Execute tudo com 1 comando ou controle cada componente individualmente.

📦 Scripts Disponíveis

Script Descrição Recomendação
iniciar-tudo.bat Inicia backend + frontend + popula dados automaticamente ⭐ MELHOR
iniciar-backend.bat Inicia apenas o backend Spring Boot (porta 8080) Controle
iniciar-frontend.bat Inicia apenas o frontend com servidor HTTP (porta 5500) Controle
inserir-dados.bat Popula banco com dados de teste (1 admin + 3 usuários + 4 unidades + 5 cursos + 3 editais) Útil
parar-sistema.bat Para todos os processos (backend e frontend) Essencial
verificar-status.bat Verifica se backend e frontend estão rodando Debug

⭐ Script Recomendado: iniciar-tudo.bat

🎯 O Jeito Mais Fácil

Este script faz TUDO automaticamente:

  • ✅ Inicia backend Spring Boot
  • ✅ Aguarda 45 segundos para inicialização completa
  • ✅ Inicia frontend (Python ou Node.js)
  • ✅ Popula banco com dados de teste

Como Usar:

.\iniciar-tudo.bat

O Que Acontece:

  1. Nova janela: SEJA SENAI Backend (console Spring Boot)
  2. Nova janela: SEJA SENAI Frontend (servidor HTTP)
  3. Terminal atual: executa script de dados

Acessar:

  • Frontend: http://localhost:5500
  • Backend: http://localhost:8080/api
  • H2 Console: http://localhost:8080/h2-console

🔑 Login Automático

Após execução, use estas credenciais:

  • Admin: admin@senai.com / Admin@123
  • Usuário: joao@teste.com / Senha@123

🔧 Scripts Individuais

1️⃣ iniciar-backend.bat

Descrição: Inicia apenas o backend Spring Boot

Como Usar:

.\iniciar-backend.bat

O Que Faz:

  • Abre nova janela com console Spring Boot
  • Inicia aplicação na porta 8080
  • Usa perfil configurado em application.properties

Verificar Sucesso:

Aguarde mensagem no console:

Started SejaSenaiApplication in X.XXX seconds

Testar:

curl http://localhost:8080/api/editais

2️⃣ iniciar-frontend.bat

Descrição: Inicia servidor HTTP para o frontend

Como Usar:

.\iniciar-frontend.bat

O Que Faz:

  • Detecta Python ou Node.js automaticamente
  • Inicia servidor HTTP na porta 5500
  • Serve arquivos de frontend-web/static/

Detecção Automática:

# Tenta Python primeiro
python -m http.server 5500

# Se não houver Python, usa Node.js
npx http-server -p 5500

Acessar:

http://localhost:5500

Parar:

  • Pressione Ctrl+C na janela do servidor
  • Ou execute .\parar-sistema.bat

3️⃣ inserir-dados.bat

Descrição: Popula banco com dados de teste

⚠️ Pré-requisito: Backend deve estar rodando!

Como Usar:

# 1. Inicie o backend primeiro
.\iniciar-backend.bat

# 2. Aguarde 30-60 segundos

# 3. Execute o script de dados
.\inserir-dados.bat

Dados Criados:

Tipo Quantidade Detalhes
Usuários 4 1 admin (admin@senai.com) + 3 alunos
Unidades 4 Brás, Vila Alpina, Ipiranga, Santo Amaro
Cursos 5 Informática, Mecânica, Eletroeletrônica, Edificações, Logística
Editais 3 Processo Seletivo 2026.1, 2026.2, 2026.3

Verificar Dados:

Acesse o H2 Console e execute:

SELECT * FROM USUARIO;
SELECT * FROM CURSO;
SELECT * FROM EDITAL;

4️⃣ parar-sistema.bat

Descrição: Para todos os processos do sistema

Como Usar:

.\parar-sistema.bat

O Que Faz:

  • 🛑 Para backend (mata processos java.exe)
  • 🛑 Para frontend (mata servidores HTTP)
  • 🛑 Fecha todas as janelas relacionadas

Quando Usar:

  • Ao terminar de usar o sistema
  • Antes de fazer mudanças no código
  • Para liberar portas 8080 e 5500
  • Quando houver erros de "port already in use"

🚨 Troubleshooting Rápido

Erro: "Port 8080 already in use"

Causa: Backend já está rodando ou outra aplicação usa a porta

Solução:

.\parar-sistema.bat
# OU
taskkill /F /IM java.exe

Erro: "Python não encontrado"

Causa: Python não instalado ou não no PATH

Solução: Script tentará Node.js automaticamente. Se não tiver nenhum:

  • Instale Python: python.org/downloads
  • Instale Node.js: nodejs.org
  • Ou abra frontend-web/static/index.html diretamente no navegador

Erro 404 ao inserir dados

Causa: Backend não está rodando ou não inicializou completamente

Solução:

# 1. Verificar
.\verificar-status.bat

# 2. Aguardar backend inicializar (30-60s)

# 3. Tentar novamente
.\inserir-dados.bat
