📋 Pré-requisitos

  • JDK 21 (ou superior) - Download
  • MySQL 8.0+ (para produção) OU H2 (integrado para testes)
  • Maven (incluído via wrapper mvnw)
  • Um navegador moderno (Chrome, Firefox, Edge)
  • Opcional: Python 3 ou Node.js para servidor HTTP local do frontend
💡 Dica: Se você não tem MySQL instalado, use o perfil h2 para testes rápidos! O H2 é um banco em memória que não requer instalação.

🎯 Opção 1: Configuração com H2 (Recomendado para Testes)

O H2 é um banco de dados em memória perfeito para desenvolvimento e testes. Não requer instalação ou configuração.

Passo 1: Configurar Perfil H2

Edite o arquivo backend/src/main/resources/application.properties:

# Altere esta linha para usar H2
spring.profiles.active=h2

Passo 2: Iniciar Backend

cd backend
.\mvnw.cmd spring-boot:run

Passo 3: Popular com Dados de Teste (Opcional mas Recomendado)

Depois que o backend iniciar, execute em outra janela do PowerShell:

powershell -ExecutionPolicy Bypass -File popular-dados-teste.ps1

Este script cria automaticamente:

  • ✅ 1 usuário administrador: admin@senai.com / Admin@123
  • ✅ 3 usuários comuns para testes
  • ✅ 4 unidades SENAI (Brás, Vila Alpina, Ipiranga, Santo Amaro)
  • ✅ 5 cursos técnicos (Informática, Mecânica, Eletroeletrônica, etc)
  • ✅ 3 editais de processo seletivo

Passo 4: Acessar H2 Console

Acesse o console web do H2 em: http://localhost:8080/h2-console

JDBC URL: jdbc:h2:mem:testdb
Username: sa
Password: (deixe em branco)
✅ Script Completo: Use iniciar-teste-completo.bat para iniciar o backend e popular dados automaticamente em um único comando!

🗄️ Opção 2: Configuração com MySQL (Produção)

Passo 1: Instalar e Configurar MySQL

  1. Instale o MySQL 8.0+ - Download
  2. Inicie o MySQL Server
  3. O banco seja_senai_db será criado automaticamente na primeira execução

Passo 2: Configurar Perfil MySQL

Edite o arquivo backend/src/main/resources/application.properties:

# Altere esta linha para usar MySQL
spring.profiles.active=mysql

Se necessário, ajuste as credenciais em backend/src/main/resources/application-mysql.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/seja_senai_db?createDatabaseIfNotExist=true
spring.datasource.username=root
spring.datasource.password=SUA_SENHA_AQUI

Passo 3: Iniciar Backend

cd backend
.\mvnw.cmd spring-boot:run

Passo 4: Popular Dados (Opcional)

O script também funciona com MySQL:

powershell -ExecutionPolicy Bypass -File popular-dados-teste.ps1

🌐 Subindo o Frontend

Opção 1: Abrir Diretamente (Mais Simples)

Navegue até frontend-web/static e abra index.html no navegador.

Nota: Funciona para a maioria das funcionalidades, mas algumas podem ter problemas com CORS.

Opção 2: Servidor HTTP Local (Recomendado)

Com Python:

cd frontend-web\static
python -m http.server 5500
# Acesse: http://localhost:5500

Com Node.js:

npx http-server frontend-web/static -p 5500
# Acesse: http://localhost:5500

Com PHP:

cd frontend-web\static
php -S localhost:5500
# Acesse: http://localhost:5500

🛠️ Troubleshooting

Erro: "Port 8080 already in use"

Outra aplicação está usando a porta 8080. Mate o processo ou altere a porta em application.properties:

server.port=8081

Erro de Conexão com MySQL

  1. Verifique se o MySQL está rodando
  2. Confirme usuário e senha em application-mysql.properties
  3. Teste a conexão: mysql -u root -p

Erro de Compilação

Limpe o projeto e recompile:

cd backend
.\mvnw.cmd clean compile

Frontend não conecta ao Backend

  1. Verifique se o backend está rodando: http://localhost:8080/api
  2. Verifique o console do navegador (F12) para erros CORS
  3. Use um servidor HTTP local ao invés de abrir o HTML diretamente
