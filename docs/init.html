Inicialização

Passo a passo para subir backend e frontend localmente.

Início Frontend Backend Resources Inicialização Snippets 📚 Documentação Completa

Pré-requisitos

  • JDK 21
  • MySQL em execução
  • Python 3 (ou outro servidor estático para frontend)

Subindo backend

cd backend
.\mvnw.cmd spring-boot:run

Subindo frontend

cd frontend-web\static
python -m http.server 5500

Links principais

  • Frontend: http://localhost:5500/login.html
  • API: http://localhost:8080/api
