📋 Pré-requisitos

  • Node.js 22+ - Download
  • Conta Supabase (PostgreSQL gerenciado na nuvem)
  • npm (incluído com Node.js)
  • Um navegador moderno (Chrome, Firefox, Edge)
  • Opcional: Python 3 para servidor HTTP local do frontend

🎯 Configuração do Ambiente

O SIGE utiliza Supabase (PostgreSQL) como banco de dados, hospedado na nuvem. Não é necessário instalar banco localmente.

Passo 1: Configurar Variáveis de Ambiente

Crie o arquivo backend/.env:

SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_KEY=SUA_CHAVE_ANON
JWT_SECRET=secreta_sige_123
PORT=8080

Passo 2: Instalar Dependências e Iniciar Backend

cd backend
npm install
npm run dev

Passo 3: Popular com Dados de Teste (Opcional mas Recomendado)

Execute o script SQL database/supabase-aluno-tables.sql no SQL Editor do Supabase (Dashboard → SQL Editor).

Este script cria automaticamente:

  • ✅ 1 usuário administrador: admin@senai.com / admin123
  • ✅ 3 usuários comuns para testes
  • ✅ 4 unidades SENAI (Brás, Vila Alpina, Ipiranga, Santo Amaro)
  • ✅ 5 cursos técnicos (Informática, Mecânica, Eletroeletrônica, etc)
  • ✅ 3 editais de processo seletivo

Passo 4: Acessar o Banco de Dados

Acesse o Supabase Studio em: Supabase Dashboard

Use o Table Editor para visualizar dados ou o SQL Editor para consultas.

✅ Script Completo: Use .\iniciar-tudo.bat para iniciar o backend e frontend automaticamente em um único comando!

🗄️ Conexão com Supabase (Produção)

Obtendo as Credenciais

  1. Acesse supabase.com e faça login
  2. Selecione o projeto SIGE
  3. Vá em Project Settings → API
  4. Copie a Project URL (SUPABASE_URL) e a anon public key (SUPABASE_KEY)

Se necessário, ajuste as credenciais em backend/src/main/resources/application-mysql.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/seja_senai_db?createDatabaseIfNotExist=true
spring.datasource.username=root
spring.datasource.password=SUA_SENHA_AQUI

Passo 3: Iniciar Backend

🌐 Subindo o Frontend

Opção 1: Abrir Diretamente (Mais Simples)

Navegue até frontend-web e abra index.html no navegador.

Nota: Funciona para a maioria das funcionalidades, mas algumas podem ter problemas com CORS.

Opção 2: Servidor HTTP Local (Recomendado)

Com Python:

cd frontend-web
python -m http.server 5500
# Acesse: http://localhost:5500

Com Node.js:

npx http-server frontend-web -p 5500
# Acesse: http://localhost:5500

Com PHP:

cd frontend-web
php -S localhost:5500
# Acesse: http://localhost:5500

🛠️ Troubleshooting

Erro: "Port 8080 already in use"

Outra aplicação está usando a porta 8080. Mate o processo ou altere a porta em backend/.env:

PORT=8081

Erro de Conexão com Supabase

  1. Verifique se as credenciais em backend/.env estão corretas
  2. Confirme se o projeto Supabase está ativo no dashboard
  3. Verifique se a chave (SUPABASE_KEY) não expirou

Erro de Dependências

Reinstale as dependências:

cd backend
rm -rf node_modules
npm install

Frontend não conecta ao Backend

  1. Verifique se o backend está rodando: http://localhost:8080/api
  2. Verifique o console do navegador (F12) para erros CORS
  3. Use um servidor HTTP local ao invés de abrir o HTML diretamente
