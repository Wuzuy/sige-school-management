## Tecnologias

### Backend
- Node.js 22
- Express 5.x
- Supabase (PostgreSQL)
- JWT (jsonwebtoken)
- bcryptjs

### Frontend
- HTML5 + CSS3
- JavaScript (vanilla)
- Notyf (notificacoes)
- Design Responsivo (Mobile-first)

### Documentacao
- HTML5 semantico
- CSS3 com variaveis customizadas
- JavaScript para interatividade
- Markdown para documentos tecnicos

## Deploy

- Frontend: Vercel (`https://sige-iota.vercel.app`)
- Backend: Render (Node.js/Express)
- Banco: Supabase (PostgreSQL)
