Banco de Dados

PostgreSQL no Supabase com 20+ tabelas, relacionamentos e seed data.

Visão Geral

O banco de dados do SIGE utiliza PostgreSQL rodando no Supabase. O schema completo está em database/schema-completo.sql. Abaixo estão listadas todas as tabelas e seus relacionamentos principais.

RBAC — Cargos e Permissões

O sistema utiliza um modelo RBAC (Role-Based Access Control) com três tabelas:

  • cargos — define os papéis (Admin Master, Secretaria, Professor, etc.)
  • permissoes — catálogo de permissões disponíveis (ex: cursos.criar, alunos.visualizar)
  • cargos_permissoes — tabela pivô que vincula permissões a cargos

O middleware requirePermissao(codigo) consulta essa tabela para verificar se o usuário logado (via id_cargo) possui a permissão necessária.
