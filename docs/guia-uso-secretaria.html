🎯 Visão Geral

Este guia apresenta todas as funcionalidades administrativas do sistema SEJA SENAI para a equipe da secretaria, incluindo gerenciamento completo do processo seletivo.

🔑 Acesso Administrativo

Email: admin@senai.com
Senha: Admin@123
Role: ADMIN (necessária para acessar o portal)

1️⃣ Acesso ao Sistema

Login como Administrador

  1. Acesse a pág de login: /login.html
  2. Insira as credenciais de administrador
  3. Você será redirecionado para /portal-secretaria.html

⚠️ Importante

Apenas usuários com role = ADMIN podem acessar o portal administrativo. Usuários comuns (alunos) serão bloqueados.

2️⃣ Portal da Secretaria - Visão Geral

O portal administrativo possui 6 abas principais:

🏫 Unidades

Gerenciar unidades do SENAI (CRUD completo)

📚 Cursos

Gerenciar cursos oferecidos (CRUD + filtros)

👥 Usuários

Gerenciar alunos e administradores

📢 Editais

Publicar editais de processo seletivo

📋 Inscrições (Principal)

Gerenciar todo o workflow do processo seletivo

📊 Relatórios

Estatísticas e dados consolidados

3️⃣ Ger Unidades

Criar Nova Unidade

  1. Clique na aba "Unidades"
  2. Clique no botão "+ Cadastrar Nova Unidade"
  3. Preencha o formulário:
    • Nome da Unidade: Ex: "SENAI Belo Horizonte"
    • Cidade: Ex: "Belo Horizonte"
    • Estado: Sigla (MG, SP, RJ)
    • Endereço: Endereço completo
    • Telefone: Contato da unidade
  4. Clique em "Salvar"

Editar/Excluir Unidade

  • Editar: Clique no botão "✏️ Editar" → Altere os dados → Salvar
  • Excluir: Clique no botão "🗑️ Excluir" → Confirme a ação

4️⃣ Gerenciar Cursos

Criar Novo Curso

  1. Clique na aba "Cursos"
  2. Clique no botão "+ Cadastrar Novo Curso"
  3. Preencha o formulário:
    • Nome do Curso: Ex: "Técnico em Automação Industrial"
    • Tipo: Técnico, Profissionalizante, etc.
    • Unidade: Selecione a unidade
    • Turno: Manhã, Tarde, Noite, Integral
    • Duração (meses): Ex: 18
    • Data de Início: Ex: 2024-02-01
    • Data de Término: Ex: 2025-08-01
    • Vagas Disponíveis: Ex: 30
    • Status: ATIVO ou INATIVO
    • Descrição: Informações detalhadas (opcional)
  4. Clique em "Salvar"

Filtros Avançados de Cursos

O sistema possui 3 campos de filtro:

  • Pesquisa por texto: Filtra por nome do curso
  • Unidade: Filtra cursos de uma unidade específica
  • Status: TODOS, ATIVO, INATIVO

💡 Dica

Mantenha apenas cursos ATIVOS visíveis para os alunos. Cursos INATIVOS não aparecem na listagem pública.

5️⃣ Gerenciar Usuários

Criar Novo Administrador

  1. Clique na aba "Usuários"
  2. Clique no botão "+ Cadastrar Novo Administrador"
  3. Preencha os dados (nome, email, CPF, telefone, senha)
  4. O sistema automaticamente atribui role = ADMIN
  5. Clique em "Salvar"

Criar Novo Aluno (Manualmente)

  1. Clique no botão "+ Cadastrar Novo Aluno"
  2. Preencha os dados completos
  3. O sistema automaticamente atribui role = USER

⚠️ Senha Padrão

Quando criar usuários manualmente, defina uma senha padrão (ex: "Senai@123") e oriente o usuário a alterá-la no primeiro login.

6️⃣ Gerenciar Editais

Publicar Novo Edital

  1. Clique na aba "Editais"
  2. Clique no botão "+ Publicar Novo Edital"
  3. Preencha:
    • Título: Ex: "Edital 01/2024 - Processo Seletivo"
    • Curso: Selecione o curso relacionado
    • Data de Abertura: Início das inscrições
    • Data de Fechamento: Fim das inscrições
    • Status: ATIVO (visível) ou INATIVO (oculto)
    • Descrição: Informações gerais
    • Requisitos: O que o candidato precisa
  4. Clique em "Publicar"

7️⃣ Gerenciar Inscrições ⭐ (Seção Principal)

Esta é a aba mais importante do sistema, onde você gerencia todo o processo seletivo.

Visão Geral da Aba

  • Lista de todas as inscrições recebidas
  • Filtros avançados: Por texto, curso e status
  • Botões de ação: Ver Detalhes para cada inscrição
  • Dashboard no topo: Cards com estatísticas rápidas

Filtros de Inscrições

Filtro Opções
Pesquisa Nome do aluno ou CPF
Curso TODOS, ou selecionar curso específico
Status TODOS, EM_ANALISE, APROVADA, REPROVADA

Workflow Completo do Processo Seletivo

O processo possui 7 etapas principais:

Etapa 1: Recebimento da Inscrição ✅

  • Aluno envia inscrição pelo sistema
  • Status inicial: EM_ANALISE
  • Aparece automaticamente na lista da secretaria

Etapa 2: Análise Documental 🔍

  1. Clique em "Ver Detalhes" na inscrição
  2. Modal abre com informações completas do aluno
  3. Verifique:
    • CPF válido e não duplicado
    • Email válido
    • Dados completos e corretos
    • Escolaridade mínima para o curso
  4. Decisão:
    • Aprovar: Clique em "✅ Aprovar" → Email automático enviado
    • Reprovar: Clique em "❌ Reprovar" → Adicione observações → Email enviado

✅ Aprovação Automática

Ao aprovar, o sistema: muda o status para APROVADA, envia email ao aluno, registra data de aprovação.

Etapa 3: Convocação para Prova 📝

  1. Na seção "Gerenciar Prova" do modal
  2. Preencha:
    • Data da Prova: Ex: 2024-03-15
    • Hora da Prova: Ex: 14:00
    • Local da Prova: Ex: "SENAI - Sala 301"
  3. Clique em "Configurar Prova"
  4. Status muda para CONVOCADO_PROVA
  5. Email automático enviado com data/hora/local

Etapa 4: Realização da Prova ✍️

  • Aluno comparece no dia/hora/local indicado
  • Prova aplicada presencialmente pela equipe
  • Correção realizada pela equipe pedagógica

Etapa 5: Registro do Resultado 🎯

  1. Na seção "Resultado da Prova" do modal
  2. Preencha:
    • Nota da Prova: Ex: 8.5
    • Resultado: APROVADO ou REPROVADO
  3. Clique em "Registrar Resultado"
  4. Se APROVADO:
    • Status muda para APROVADO_PROVA
    • Status matrícula = PENDENTE
    • Email enviado com a boa notícia
  5. Se REPROVADO:
    • Status muda para REPROVADO_PROVA
    • Email enviado

Etapa 6: Processo de Matrícula 📋

  1. Aluno acessa o portal e aceita o contrato
  2. Na secretaria, vá para "Gestão de Matrícula"
  3. Altere o status para: CONCLUIDA
  4. Clique em "Processar Matrícula"
  5. Ações automáticas do sistema:
    • ✅ Gera número de matrícula único (SENAI-2024-XXXXXX)
    • ✅ Cria carteirinha virtual em PDF
    • ✅ Envia email com PDF anexado
    • ✅ Gera QR Code para validação

🎓 Carteirinha Automática

O sistema gera a carteirinha automaticamente ao concluir a matrícula! O aluno receberá o PDF por email.

Etapa 7: Lista de Espera (Se necessário) ⏳

  • Se o curso lotou e há candidatos aprovados sem vaga
  • Clique em "Adicionar à Lista de Espera"
  • Status muda para LISTA_ESPERA
  • Quando abrir vaga, remova da lista e prossiga com matrícula

8️⃣ Relatórios e Estatísticas

Aba Relatórios

O sistema gera 3 tipos de relatórios:

1. Inscrições por Curso

  • Gráfico de barras mostrando quantidade de inscrições por curso
  • Tabela com: Nome do curso, Total de inscrições
  • Útil para identificar cursos mais procurados

2. Status das Inscrições

  • Gráfico de pizza com distribuição por status
  • Quantidade de: EM_ANALISE, APROVADA, REPROVADA, etc.
  • Útil para monitorar o andamento geral

3. Taxa de Aprovação

  • Percentual de aprovação vs reprovação
  • Por curso e geral
  • Útil para análise de qualidade

9️⃣ Casos de Uso Comuns

Caso 1: Processo Seletivo Completo

  1. Crie uma nova unidade (se não existir)
  2. Cadastre o curso desejado
  3. Publique um edital para o curso
  4. Aguarde inscrições dos alunos
  5. Analise cada inscrição (aprovar/reprovar)
  6. Configure a prova para os aprovados
  7. Após a prova, registre os resultados
  8. Processe as matrículas dos aprovados
  9. Sistema gera carteirinhas automaticamente

Caso 2: Reprovar Inscrição por Documentação Irregular

  1. Abra os detalhes da inscrição
  2. Clique em "❌ Reprovar"
  3. No campo observações, explique o motivo (ex: "CPF inválido")
  4. Confirme → Aluno recebe email com a justificativa

Caso 3: Adicionar Candidato à Lista de Espera

  1. Candidato foi aprovado mas o curso lotou
  2. Abra os detalhes da inscrição
  3. Clique em "⏳ Adicionar à Lista de Espera"
  4. Quando uma vaga abrir, retorne e prossiga com a matrícula

Caso 4: Alterar Dados de um Aluno

  1. Vá para a aba "Usuários"
  2. Encontre o aluno na lista
  3. Clique em "" Editar"
  4. Altere telefone, endereço, etc.
  5. Salve → Aluno verá alterações no próximo login

🔧 Troubleshooting

Problema: Não consigo ver a aba "Inscrições"

Solução: Verifique se você está logado com uma conta ADMIN. Apenas administradores têm acesso.

Problema: Filtros não funcionam

Solução: Recarregue a página (F5). Se persistir, limpe o cache do navegador.

Problema: Email não foi enviado ao aprovar inscrição

Solução: Verifique configurações SMTP em application.properties. Teste conexão com o servidor de email.

Problema: Carteirinha não foi gerada

Solução: Verifique logs do backend. Certifique-se de que as bibliotecas iText7 e ZXing estão no classpath.

Problema: Lista de inscrições vazia

Solução: Verifique se há inscrições no banco. Execute popular-dados-teste.ps1 para popular dados de teste.
