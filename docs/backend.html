Camadas

  • Model: entidades JPA (Usuario, Curso, Unidade, Inscricao, Edital).
  • Repository: interfaces Spring Data para persistência.
  • Controller: APIs REST para operações de negócio.
  • Security: JWT stateless com regras por rota e perfil.
