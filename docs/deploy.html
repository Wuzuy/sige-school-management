Guia de Deploy

Instruções para deploy do frontend, backend e aplicativo mobile em produção.

Visão Geral

ComponentePlataforma
Frontend Web (3 portais)Vercel
Backend (Express)Render
Aplicativo MobileExpo (EAS Build)
Banco de DadosSupabase

1. Banco de Dados — Supabase

O banco de dados PostgreSQL está hospedado no Supabase. Siga os passos abaixo para configurar:

  1. Crie uma conta em supabase.com
  2. Crie um novo projeto e anote a URL do projeto e a chave anon (public)
  3. No SQL Editor, execute o script database/schema-completo.sql para criar todas as tabelas
  4. Execute o script de seed para popular os dados iniciais
As variáveis SUPABASE_URL e SUPABASE_KEY serão usadas na configuração do backend.

2. Backend — Render

O backend Express é deployado no Render como um serviço web.

Passos

  1. Crie uma conta em render.com
  2. Conecte seu repositório GitHub
  3. Crie um Web Service apontando para o diretório backend/
  4. Configure o start command: npm start
  5. Defina o Health Check Path: /api/usuarios/login

Variáveis de Ambiente

PORT=8080
SUPABASE_URL=https://seu-projeto.supabase.co
SUPABASE_KEY=sua-chave-anon

Build Command

npm install
O backend escuta na porta 8080 (definida via variável PORT).

3. Frontend — Vercel

Os três portais web (Inscrição, Escolar e Secretaria) são deployados no Vercel como sites estáticos.

Passos

  1. Crie uma conta em vercel.com
  2. Conecte seu repositório GitHub
  3. Crie um projeto apontando para frontend-web/
  4. Configure Build Command como vazio (HTML estático)
  5. Configure Output Directory como .

API Config

O frontend detecta automaticamente o ambiente:

  • Localhost: usa http://localhost:8080/api
  • Vercel: usa https://sige-1gqx.onrender.com/api

Para sobrescrever manualmente:

localStorage.setItem('API_BASE_URL', 'https://sige-1gqx.onrender.com/api');

Portais

  • /portal-inscricao/ — Login, Cursos, Inscrição, Matrícula, Status, Recuperar Senha, Créditos
  • /portal-escolar/ — Dashboard, Perfil, Histórico, Frequência, Horários, etc.
  • /portal-secretaria/ — SPA administrativa completa

4. Aplicativo Mobile — EAS Build

O aplicativo React Native é construído e publicado via Expo Application Services (EAS).

Pré-requisitos

npm install -g eas-cli
eas login

Build Android

cd mobile-app
eas build --platform android

Build iOS

cd mobile-app
eas build --platform ios

Configuração do EAS

O arquivo eas.json contém as configurações de build. Certifique-se de que o app.json possui as variáveis de ambiente corretas para apontar para o backend em produção.

API Base no Mobile

const API_BASE = 'https://sige-1gqx.onrender.com/api';

Resumo de Variáveis de Ambiente

VariávelOnde usarDescrição
PORTBackend (Render)Porta do servidor Express (8080)
SUPABASE_URLBackend (Render)URL do projeto Supabase
SUPABASE_KEYBackend (Render)Chave anon/public do Supabase
API_BASE_URLFrontend (localStorage)Sobrescreve URL da API no frontend

Desenvolvimento Local

# Backend
cd backend
npm install
cp .env.example .env  # configurar SUPABASE_URL e SUPABASE_KEY
npm start

# Mobile
cd mobile-app
npm install
npx expo start

# Frontend (servidor HTTP simples)
cd frontend-web
npx http-server -p 3000
