Política de Privacidade

Última atualização: fevereiro de 2026

A sua privacidade é importante para nós. Esta Política de Privacidade descreve como o SIGE coleta, utiliza, armazena e protege os dados pessoais dos usuários, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei n° 13.709/2018).

1. Dados Coletados

Durante o uso do sistema, podemos coletar os seguintes dados pessoais:

  • Nome completo
  • CPF e RG
  • Data de nascimento
  • Endereço de e-mail
  • Número de telefone
  • Escolaridade declarada
  • Dados acadêmicos (matrícula, notas, frequência)

2. Finalidade do Tratamento

Os dados coletados são utilizados exclusivamente para:

  • Processar inscrições e matrículas em cursos
  • Gerenciar o histórico acadêmico do aluno
  • Emitir documentos e carteirinhas digitais
  • Controlar acesso físico às dependências da instituição
  • Comunicar informações institucionais relevantes

3. Compartilhamento de Dados

O SIGE não compartilha dados pessoais com terceiros, exceto quando exigido por lei ou mediante autorização expressa do titular.

4. Armazenamento e Segurança

Os dados são armazenados em servidores seguros com criptografia (bcrypt) e controle de acesso baseado em funções (RBAC), garantindo que apenas pessoas autorizadas tenham acesso às informações.

5. Direitos do Titular

Conforme a LGPD, você tem direito a:

  • Confirmar a existência de tratamento dos seus dados
  • Acessar seus dados pessoais
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a anonimização, bloqueio ou eliminação de dados desnecessários
  • Solicitar a portabilidade dos dados
  • Revogar o consentimento a qualquer momento

Para exercer seus direitos, entre em contato com o Encarregado (DPO).

6. Consentimento

Ao realizar a inscrição no sistema, você manifesta seu consentimento livre, informado e inequívoco para o tratamento dos dados pessoais aqui descritos. Você pode revogar este consentimento a qualquer momento através do contato com o DPO.

7. Retenção dos Dados

Os dados serão mantidos pelo período necessário ao cumprimento das finalidades descritas ou conforme obrigação legal. Após este período, serão eliminados de forma segura.

8. Encarregado (DPO)

Encarregado pela Proteção de Dados (DPO)

E-mail: dpo@sige.com.br

Prazo para resposta: até 5 dias úteis

9. Alterações nesta Política

Esta política pode ser atualizada periodicamente. Recomendamos a consulta regular para ciência de eventuais mudanças.
