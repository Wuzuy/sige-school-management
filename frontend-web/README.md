# Frontend Web

Interface web desenvolvida em **HTML**, **CSS** e **JavaScript** para inscrição de alunos e administração do sistema.

## Tecnologias
- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap (opcional)

## Estrutura
```
frontend-web/
├── index.html
├── admin/
│   └── index.html
├── inscricao/
│   └── index.html
├── css/
├── js/
└── README.md
```

## Executar
Abrir os arquivos HTML diretamente no navegador ou usar um servidor local:
```bash
python -m http.server 8000
```
