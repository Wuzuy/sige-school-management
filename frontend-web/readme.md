# Frontend - SEJA SENAI

Interface web do sistema de inscrição e dashboard de cursos.

## Tecnologias

* HTML5
* CSS3
* JavaScript (Vanilla)

## Como Executar Localmente

1. Navegue até a pasta `frontend-web`.
2. Abra o arquivo `login.html` ou `index.html` diretamente no seu navegador.
3. Recomendamos usar a extensão **Live Server** no VS Code para auto-reload.

## Estrutura de Pastas Sugerida

* `/css`: Folhas de estilo globais e específicas de componentes.
* `/js`: Scripts de validação e consumo da API.
* `/assets`: Imagens, ícones e fontes.
